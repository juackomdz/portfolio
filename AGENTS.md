# AGENTS.md — Nuxt 4 Portfolio

## Commands

```bash
npm run dev          # dev server (port 3000)
npm run build        # production build
npm run generate     # static export (nuxt generate)
npm run preview      # preview production build
npm run postinstall  # required after dep changes (runs: nuxt prepare)
```

## Key Dependencies

- `nuxt` v4, `vue` 3.5, `vue-router` 5.1
- `tailwindcss` v4 via `@tailwindcss/vite` plugin (`nuxt.config.ts:32-34`)
- `shadcn-nuxt` — shadcn-vue component system (`components.json` config, `style: "new-york"`, `font: "inter"`)
- `@nuxtjs/color-mode` — class-based dark mode (`portfolio-color-mode` storage key, class suffix `""`)
- `motion-v/nuxt` — Vue Motion animations
- `@vueuse/nuxt` — composables auto-imported
- `@nuxt/icon` — SVG icon bundle (`clientBundle: { scan: true, sizeLimitKb: 0 }`, `mode: "svg"`, `serverBundle: "local"`)
- `reka-ui` — headless UI primitives (used by shadcn-vue)
- `class-variance-authority`, `clsx`, `tailwind-merge` — styling utilities; `cn()` in `app/lib/utils.ts`
- `tailwind-variants` — `tv` and `VariantProps` available
- `@google/genai`, `@modelcontextprotocol/sdk` — ChatBot AI integration
- `@nuxt/image` — image optimization
- `zod` — schema validation
- `runtimeConfig.geminiApiKey` — Gemini API key (empty default, set via env)

## Tailwind v4

- Entry: `app/assets/css/tailwind.css` (imported via `css: ['~/assets/css/tailwind.css']`)
- `tw-animate-css` plugin imported in CSS
- `@tailwindcss/forms` with `strategy: "class"` — form inputs require `form-*` classes
- **BoldKit theme**: HSL-based color system (light + `.dark` mode), neon/clash accent palettes, custom easing tokens (`--ease-out-*`, `--bk-ease-snap`)
- `--radius: 0rem` — sharp corners (neubrutalism style)
- `@custom-variant dark (&:is(.dark *))` — dark mode via `.dark` class on `<html>`, not media query

## Component System

- **shadcn-vue** components live in `app/components/ui/` (lowercase `ui/`)
  - Standard: Card/\*, Badge, Button, Input
  - Custom: Sticker, StickyNote, Stamp, canvas-effects/DotWave
  - Shapes: `app/components/ui/shapes/` (~60+ shape components, exported from `shapes/index.ts`)
  - Variants: `button-variants.ts`, `sticker-variants.ts`
- **Adding shadcn components**: `npx shadcn-vue add <component>` (uses `components.json` config)
- **BoldKit registry**: `@boldkit` registry configured in `components.json:23-25`
- **App components** at `app/components/` (Hero, Footer, Navigation, Projects, Experience, Testimonial, ChatBot, Portfolio)

## Architecture

- Single-page portfolio — all components composed in `app/app.vue` (no `pages/` directory, no routing)
- `app/lib/utils.ts` — `cn()` utility (clsx + tailwind-merge)
- `app/utils/data.ts` — portfolio data, `app/utils/types.ts` — shared types
- No `composables/` or `plugins/` exist yet

## TypeScript

- `tsconfig.json` references `.nuxt/tsconfig.*.json` (app, server, shared, node — generated by `nuxt prepare`)
- No explicit `compilerOptions` — inherits from Nuxt

## Gotchas

- Always run `npm run postinstall` after adding/removing deps to regenerate `.nuxt/` types
- Dark mode uses `.dark` class on `<html>` (not media query); `@custom-variant dark` in CSS
- No CI, no ESLint/Prettier config, no test framework set up
- Icon `fetchTimeout: 2000` — network icons may fail silently in slow environments
- `lang="es"` on `<html>` — Spanish locale for SEO metadata
